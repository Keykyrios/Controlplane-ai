## Problem

Every deployed AI system carries three simultaneous liabilities: it can be **confidently wrong**, it can **silently waste compute**, and it can **violate a safety/fairness/governance constraint**. These three failure modes are structurally different objects, measured on different timescales, and monitored — when they are monitored at all — by three unrelated tools that never talk to each other.

The response that is most dangerous to a business is rarely the one that is badly wrong on a single axis. It is the one that is **simultaneously wrong, expensive to unwind, and non-compliant** — and the correlation structure between the three axes carries information that no single axis carries alone.

## Mathematical Framework

### The Three Risk Observables

For a response $x_t$ produced at discrete index $t$ by an arbitrary model $\mathcal{M}$, we define three scalar risk observables:

**Performance risk** — large when the model is confident and independent verifiers disagree:

$$p_t = \hat{y}_t \cdot (1 - q_t)$$

where $\hat{y}_t$ is model confidence and $q_t$ is a calibrated correctness estimate from an ensemble of lightweight verifiers (retrieval cross-checks, self-consistency sampling, tool-grounded assertions).

**Cost risk** — logistic squashing of relative cost overrun into $[0,1]$:

$$c_t = \sigma\biggl(\frac{\kappa_t - \bar{\kappa}(\tau_t)}{\bar{\kappa}(\tau_t)}\biggr), \quad \sigma(z) = \frac{1}{1+e^{-z}}$$

**Responsibility risk** — coordinate-wise maximum of bias, safety, and data-leakage scores:

$$r_t = \max(b_t, s_t, \ell_t)$$

reflecting that a response is only as safe as its worst violated constraint.

### Lifting to Clifford Algebra Cl(3,0)

Treating $(p_t, c_t, r_t)$ as independently thresholded scalars discards interaction structure. We lift them into a single **risk multivector** in the geometric algebra $\text{Cl}(3,0)$ generated by orthonormal frame $\{e_1, e_2, e_3\}$ with $e_i e_j + e_j e_i = 2\delta_{ij}$:

$$R_t = p_t\, e_1 + c_t\, e_2 + r_t\, e_3 + \pi_{12}\, e_{12} + \pi_{13}\, e_{13} + \pi_{23}\, e_{23} + \pi_{123}\, e_{123}$$

The bivector coefficients capture pairwise co-occurrence excess over independence:

$$\pi_{ij} = \Pr[\text{axis } i,j \text{ jointly exceed threshold} \mid x_t] - \Pr[\text{axis } i \text{ exceeds}] \cdot \Pr[\text{axis } j \text{ exceeds}]$$

The **wedge product** between consecutive risk vectors detects qualitatively new failure mode combinations:

$$\|\vec{R}_t \wedge \vec{R}_{t-1}\| = \|\vec{R}_t\|\,\|\vec{R}_{t-1}\|\,\sin\theta_t$$

This is nonzero exactly when the risk vector has **rotated** in performance-cost-responsibility space — a novel failure mode has appeared, not just a quantitative increase along an already-observed direction.

### Hyperdimensional Fingerprinting

Each response is encoded into a $D$-dimensional bipolar fingerprint via bind ($\otimes$) and bundle ($\oplus$):

$$h_t = \bigoplus_{k=1}^{n_t} \big(h_{\text{tok}}(w_k) \otimes h_{\text{pos}}(k)\big)$$

Encoding cost: $T_{\text{encode}}(n_t) = O(n_t \cdot D)$, executable via SIMD in well under a millisecond for $D=10{,}000$.

### Topological Drift via Persistent Homology

We track the **shape** of the distribution of recent responses using the Vietoris-Rips filtration over the fingerprint sliding window $X_t = \{h_{t-w+1}, \dots, h_t\}$. The drift score is the 2-Wasserstein distance between the current persistence diagram and a reference:

$$\Delta_t = W_2(D_t, D_0) = \biggl(\inf_{\gamma} \sum_{u \in D_t} \|u - \gamma(u)\|_2^2\biggr)^{1/2}$$

By the **stability theorem** (Cohen-Steiner, Edelsbrunner, Harer): $d_B(D(X), D(X')) \le \|X - X'\|_\infty$ — the persistence diagram changes by at most as much as the data changes.

### Algorithmic Surprise via Normalized Compression Distance

A task-agnostic anomaly signal grounded in algorithmic information theory:

$$\text{NCD}(x, y) = \frac{C(xy) - \min(C(x), C(y))}{\max(C(x), C(y))}$$

$$\text{Surprise}(x_t) = \min_{v \in \mathcal{V}} \text{NCD}(\tilde{h}_t, \tilde{v})$$

An admissible normalized approximation of Kolmogorov information distance, domain-agnostic by construction.

### Non-Hermitian Spectral Early Warning

The risk-propagator Jacobian $J_t = \frac{\partial s_{t+1}}{\partial s_t} \in \mathbb{R}^{3 \times 3}$ is generically **non-normal** ($J_t J_t^\top \ne J_t^\top J_t$), so eigenvalues alone do not control transient behavior. We track the eigenvector condition number:

$$\kappa(V_t) = \|V_t\| \cdot \|V_t^{-1}\|$$

As $J_t$ approaches an **exceptional point** (two eigenvalues and eigenvectors coalesce), $\kappa(V_t) \to \infty$. A rising $\kappa(V_t)$ over consecutive turns is the mathematical signature of an imminent hallucination cascade — it fires **before** any fixed threshold is crossed.

For agentic sessions, this extends to a block-structured propagator over the agent action graph:

$$J_t^{\mathcal{A}} = \begin{bmatrix} J_{11} & J_{12} & \cdots \\ J_{21} & J_{22} & \cdots \\ \vdots & & \ddots \end{bmatrix}, \quad J_{ab} = \frac{\partial s_{t+1}^{(b)}}{\partial s_t^{(a)}}$$

### Sheaf-Theoretic Fusion

A cellular sheaf $\mathcal{F}$ on the pipeline graph assigns local risk-assessment spaces to each checkpoint. The **sheaf Laplacian**:

$$L_{\mathcal{F}} = \delta^\top \delta, \quad H^0(G;\mathcal{F}) = \ker L_{\mathcal{F}}$$

The **discord score** measures disagreement between sub-checks as a first-class quantity:

$$\text{Discord}_t = x_t^\top L_{\mathcal{F}} x_t = \|\delta x_t\|^2$$

### Tropical Routing

The routing policy is a **tropical (max-plus) polynomial** — provably piecewise-linear with an explicit combinatorial description:

$$\phi_a(z) = \max_{1 \le k \le m_a}\biggl(w_{a,k} + \sum_{i=1}^{7} \alpha_{a,k,i} z_i\biggr)$$

$$a^*(z) = \arg\max_a \phi_a(z), \quad a \in \lbrace\text{pass, edit, block, escalate}\rbrace$$

Every coefficient $w_{a,k}$ and exponent $\alpha_{a,k,i}$ is individually inspectable and auditable.

### Conformal Risk Control

Per-tier thresholds are calibrated by distribution-free conformal risk control. For a calibration set of $n$ exchangeable pairs, the threshold:

$$\hat{\lambda} = \inf\bigl\lbrace\lambda \in \Lambda : \tfrac{n}{n+1}\hat{R}_n(\lambda) + \tfrac{B}{n+1} \le \alpha\bigr\rbrace$$

guarantees:

$$\mathbb{E}[L_{n+1}(\hat{\lambda})] \le \alpha$$

The expected false-negative rate on a fresh, unseen response is controlled at level $\alpha$, tight up to $O(1/n)$.

### Queueing-Theoretic Latency Guarantee

Fast path modeled as $M/M/1$ with service rate $\mu_{\text{fast}} \gg \lambda$:

$$L_{\text{fast}} = \frac{1}{\mu_{\text{fast}} - \lambda}$$

Architecturally decoupled from the human escalation queue — the escalation path can be arbitrarily backlogged without adding a single millisecond to the traffic that doesn't need it.

### Post-Quantum Encryption (Real-Time Hybrid PQC)

Every audit record is encrypted in real time with a **production-grade hybrid post-quantum scheme**:

```
Step 1: ML-KEM-768 encapsulate()    → pq_shared_secret (32 bytes) + kem_ciphertext (1088 bytes)
Step 2: X25519 ephemeral ECDH       → classical_shared_secret (32 bytes)
Step 3: HKDF-SHA256(pq ‖ classical) → aes_key (32 bytes)
Step 4: AES-256-GCM(aes_key, nonce) → encrypted audit record payload
```

The hybrid construction (ML-KEM-768 lattice-based FIPS 203 + X25519 elliptic curve) ensures security against both classical and quantum adversaries. Implemented via `cryptography>=47.0.0` (`pyca/cryptography`) — the industry-standard, audited Python crypto library with native ML-KEM-768 support. All encrypted records are appended to the hash-linked CRDT audit ledger (`services/audit-ledger/main.py`) and remain fully queryable and decryptable by compliance officers.

## Quick Start

### Prerequisites
- Python 3.12+ with `pip install fastapi uvicorn httpx numpy scipy cryptography pydantic`
- Node.js 18+ (for the dashboard)

### One-Command Startup

```bash
# Install frontend dependencies (first time only)
cd frontend && npm install && cd ..

# Start everything — all 17 backend services + frontend dashboard
python start.py
```

This launches all 17 microservices (ports 8000–8016) and the frontend at **http://localhost:5183** (or **http://localhost:5173**).
Press `Ctrl+C` to stop everything.

### Run Demo Scenarios

```bash
# With all services running:
python demo/scenario_1_routine_pass.py
python demo/scenario_2_confident_wrong_biased_tierC_block.py
python demo/scenario_3_same_output_tierA_edit.py
```

Or use the dashboard directly — click any scenario in the **Ops Dashboard** to send it through all 17 services live.
